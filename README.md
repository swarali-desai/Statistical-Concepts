# Statistical-Concepts

Practicing statistical concepts on real-world or synthetic data, applied end-to-end rather
than in isolated snippets.

## [OptiFlow — A/B Testing & Experimentation Platform](OptiFlow-AB-Analysis-System/)

An end-to-end A/B testing / experimentation system for a checkout-flow redesign: synthetic
data generation with realistic novelty effects and heterogeneous treatment effects, power
analysis, CUPED variance reduction, sequential (always-valid) testing, Bayesian A/B testing,
subgroup analysis, and a ship/hold/don't-ship decision framework — plus an interactive
Streamlit dashboard and a fully narrated notebook.
